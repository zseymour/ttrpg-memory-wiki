# Bounded recall uses validated plans and deterministic closure

Campaign-memory recall uses attributed, lens-bound plans for adaptable situation-specific relevance, while a deterministic root-relative invariant kernel owns identity, lifecycle, conflict, uncertainty, provenance, safety, snapshot, budget, and completeness closure. Recall results are non-authoritative structured views under hard representation-aware budgets: required omissions become explicit Recall gaps, optional exclusions remain inspectable without leaking hidden material, and graph, temporal, or semantic enrichment can consume only the remainder. This preserves provider-neutral associative retrieval without allowing model relevance, prompt summaries, or rebuildable projections to confer authority or hide incomplete recall.
